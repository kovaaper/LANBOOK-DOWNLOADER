# LANBOOK-DOWNLOADER
ЭБС Лань+PDF — простая программа, которая дает вам обход на ограничение скачивания книг в ЭБС Лань и сохраняет их в PDF.
Войдите в свой аккаунт через браузер, вставьте ссылку на книгу и выберите, что сохранить: весь документ или отдельные страницы. Программа получает PDF, загруженный читалкой, и сохраняет его на компьютер.
Возможности:
- Вход через браузер без ручного копирования cookies.
- Сохранение сессии между запусками.
- Загрузка целой книги или выбранного диапазона страниц.
- Сохранение исходного оформления PDF.

Для работы нужны Windows или Linux (Ubuntu 24.04/26.04, Debian 12/13), Python 3.11 или новее и аккаунт с доступом к нужной книге. Программа использует права вашей учётной записи и не обходит ограничения доступа.
